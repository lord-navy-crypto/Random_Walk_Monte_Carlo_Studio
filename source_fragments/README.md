# Supplied source fragments

These files are supplied reconstruction references organized under stable repository names:

- `original_report.pdf` — written assignment/report fragment.
- `original_random_walk_f.py` — random-walk implementation fragment.
- `original_monte_carlo_n.py` — Monte Carlo/grid implementation fragment.
- `original_plotting_mc.ipynb` — plotting/error-bar/3D visualization fragment.

For the V4 English-only edition, comments in the Python and notebook fragments were translated to English without changing their computational statements. The PDF and Monte Carlo Python fragment remain byte-for-byte unchanged. Corrected production implementations live under `rw_mc_studio/`; `SOURCE_MAPPING.md`, `AUDIT_REPORT.md`, and `SEMANTIC_GLOSSARY.md` document the differences.

`SHA256SUMS.txt` provides integrity hashes for the packaged references. See `NOTICE.md` before redistributing material whose original license is unknown.
