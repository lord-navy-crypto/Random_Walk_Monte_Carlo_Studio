# Fragment reconstruction

The third fragment (`mc (1)(1).ipynb`) is not itself a Monte Carlo engine. It is a plotting-capability
test containing: a sine/cosine curve + scatter plot, an error-bar plot with random errors, and a 3D
surface plot. Its useful contribution is therefore visualization intent: uncertainty/error bars, 2D
plotting, high-resolution figure export, and 3D visualization.

The actual scientific core is reconstructed from the other fragments and integrated into the
Streamlit application.
